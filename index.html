⚙️ 설정

키는 이 브라우저(localStorage)에만 저장되고 어디로도 보내지 않습니다. 비우고 저장하면 삭제됩니다.

Google Gemini (무료 AI)

미입력
키 발급받기 ↗
무료 키 발급 3분 안내
  1. aistudio.google.com/apikey 접속 → 구글 로그인
  2. Create API key 누르고 프로젝트 선택(없으면 자동 생성)
  3. AIza…로 시작하는 키 복사 → 위 칸에 붙여넣기 → 저장

무료 등급은 하루 수백 회 수준으로 충분합니다. 결제 카드 등록 없이 쓸 수 있습니다. (정확한 한도는 구글 정책에 따라 달라집니다.)

YouTube Data API v3

미입력
키 발급받기 ↗
무료 키 발급 안내 · 하루 한도
  1. Google Cloud Console → 새 프로젝트
  2. YouTube Data API v3 사용 설정
  3. 사용자 인증 정보 → API 키 만들기 → 복사

무료 한도는 하루 10,000 유닛이고, 검색 1회가 100유닛입니다(하루 약 100회 검색). 조회수·길이는 영상 1개당 1유닛이라 저렴합니다.

유료 AI 영상 확장 슬롯 연동 준비

나중에 유료 AI 영상 API를 붙일 자리입니다. 키를 저장해 두면 그대로 보관되고, 지금은 영상 생성에 사용되지 않습니다. 연동되면 이 화면에서 바로 켜집니다.

⬇ PC용 패키지 내려받기 (zip)

정보

버전 1.0 · 정적 웹앱(GitHub Pages) · 설치 없이 사용

브라우저: Chrome·Edge·삼성 인터넷 권장. Safari는 영상 저장이 MP4로 됩니다.

원클릭 콘텐츠 스튜디오 · 무료 배포판

3분 사용법

  1. 만들기 탭에 주제를 한 줄 적고 프리셋을 고른 뒤 ⚡ 초안 만들기
  2. 자동으로 대본 탭으로 넘어갑니다. 컷별 자막을 고치고 유튜브 제목·설명을 복사하세요.
  3. 영상 탭에서 사진을 고르고 영상 만들기를 누르면 9:16 파일이 저장됩니다.

꼭 알아 두세요

  • AI 대본은 설정에 넣은 Gemini 무료 키가 있을 때 켜집니다. 없으면 내장 템플릿 초안이 나옵니다.
  • 브라우저 영상은 무음입니다. 음성까지 넣으려면 PC용 패키지를 쓰세요.
  • 무료 이미지는 Wikimedia Commons에서만 가져오며, 파일별 라이선스와 출처를 화면에 표시합니다. 상업적 사용 전 라이선스를 한 번 확인하세요.
  • 영상은 실시간으로 그려지므로 길이만큼 시간이 걸립니다(40초 영상 ≈ 40초).
